# Спецификация react-headless-mde

Документ описывает поведение всех команд (кнопок) редактора и внутренних компонентов.
Спецификация собрана по юнит-тестам (`src/**/__tests__/**`), каждое описанное поведение
подтверждено тестами.

## Обозначения

- `|` — позиция курсора (схлопнутое выделение);
- `[текст]` — выделенный диапазон текста;
- `→` — результат выполнения команды;
- Выделение после выполнения команды указано в конце каждого примера.

## Командная модель (v3, issue #22)

1. Команда — это **класс**, наследующий `BaseCommand<Context = void>`; экземпляр получает
   `TextController` через конструктор (создаётся хуком лениво при первом выполнении).
2. Хук `useTextAreaMarkdownEditor({ commandMap })` принимает карту **camelCase-имя → класс**
   и возвращает `{ ref, textController, commands }`.
3. `commands` — объект типизированных экзекьюторов:
   - команда без контекста вызывается без аргументов: `commands.bold()`; `commands.bold(42)` —
     ошибка компиляции;
   - команда с контекстом (`BaseCommand<number>`) требует аргумент: `commands.attach(42)`;
     `commands.attach()` — ошибка компиляции.
4. Оркестрация при вызове экзекьютора: если у команды есть `undo` и `shouldUndo(context)`
   вернул `true` — выполняется `undo(context)`, иначе `do(context)`. Повторное нажатие кнопки
   на отформатированном тексте **снимает форматирование**.
5. `commands`, `textController` и `ref` стабильны между ререндерами, пока не меняется
   **набор имён** команд; при смене реализации команды (тот же ключ, другой класс)
   экзекьюторы не пересоздаются, а инстанс заменяется при следующем вызове.
6. Вызов «отсоединённого» экзекьютора (деструктурированного ранее) после удаления команды
   из `commandMap` бросает `Cannot execute command. Command not found: <name>`.
7. Иерархия базовых классов для встроенных и пользовательских команд:
   - `WrapCommand` — оборачивание слова/выделения в prefix/suffix (bold, italic, …);
   - `LinePrefixCommand` — префикс в начало каждой затронутой строки (quote, заголовки);
   - `ListCommand` — построчные списки с отбивкой пустыми строками внутри абзаца.

## Общие принципы

1. **Курсор внутри слова** — команды слов (bold, italic, strikethrough, code, codeBlock,
   link, image) сначала выделяют слово целиком. Разделители слов: пробел и перевод строки.
2. **Построчные команды** (quote, заголовки, списки) расширяют выделение до целых строк
   и префиксуют каждую строку.
3. После выполнения команды выделение, как правило, остаётся на исходном тексте **без**
   markdown-маркеров — так пользователь может сразу продолжить печатать.

## Команды форматирования слов (WrapCommand, поддерживают undo)

### BoldCommand (жирный, `**`)

- **Действие:** оборачивает выделенный текст в `**...**`.
- **Пример:** `hello [world]` → `hello **[world]**`.
- **Курсор внутри слова:** `hello wo|rld` → `hello **[world]**`.
- **Курсор сразу после слова:** `hello|` → `**[hello]**`.
- **Нет слова под курсором:** `hello |` → `hello **|**` (пустые маркеры, курсор по центру).
- **Пустой редактор:** → `**|**`.
- **Повторное нажатие (undo):**
  - выделенное слово в маркерах: `hello **[world]**` → `hello [world]`;
  - курсор внутри маркированного слова: `hello **wo|rld**` → `hello [world]`;
  - пустые маркеры: `**|**` → удаляются;
  - bold-italic: `***wo|rld***` → `*[world]*` (снимается только bold).

### ItalicCommand (курсив, `*`)

- **Действие:** `hello [world]` → `hello *[world]*`.
- **Повторное нажатие (undo):** `hello *[world]*` → `hello [world]`.
- **Курсив поверх жирного:** `**[world]**` не считается курсивом (рядом с маркером стоит
  вторая `*`), поэтому `do` добавляет курсив: → `***[world]***`.

### StrikethroughCommand (зачёркнутый, `~~`)

- **Действие:** `hello [world]` → `hello ~~[world]~~`.
- **Повторное нажатие (undo):** `hello ~~[world]~~` → `hello [world]`.

### CodeCommand (строчный код, `` ` ``)

- **Действие:** `hello [world]` → `` hello `[world]` ``.
- **Повторное нажатие (undo):** `` hello `[world]` `` → `hello [world]`.

---

## CodeBlockCommand (без undo)

- **Однострочный текст** — оборачивается в одинарные бэктики, как CodeCommand:
  `hello [world]` → `` hello `[world]` ``.
- **Курсор внутри слова** — слово выделяется и оборачивается.
- **Пустой редактор** — `` `|` `` (курсор между бэктиками).
- **Многострочное выделение** — блок из тройных бэктиков:
  `[line1`<br>`line2]` → ` ``` `[line1<br>line2]` ``` ` (значение: ` ```\nline1\nline2\n``` `).
- **Блок внутри другого текста** — пустые строки до и после:
  `start\n[line1\nline2]\nend` → `start\n\n```\nline1\nline2\n```\n\nend`.

---

## LinkCommand (без undo)

- **Действие:** превращает выделенный текст в `[текст](url)`; выделяется заглушка `url`,
  чтобы её можно было сразу заменить.
- **Пример:** `hello [world]` → `hello [world]([url])` (значение `hello [world](url)`,
  выделен `url`).
- **Курсор внутри слова:** `hello w|orld` → то же для слова.
- **Пустой редактор:** `[]([url])`.

## ImageCommand (без undo)

- **Выделен текст:** `my [cat]` → `my ![]([cat])` (значение `my ![](cat)`).
- **Курсор внутри слова:** `my c|at` → `my ![]([cat])`.
- **Пустой редактор:** `![](https://example.com/your-image.png)`, URL целиком выделен.

## Построчные команды (LinePrefixCommand — с undo; ListCommand — без undo)

Выделение расширяется до целых строк; префикс ставится в начало каждой строки.
Выделение после: одна строка — контент без префикса; несколько строк — весь блок.
У QuoteCommand и команд заголовков повторное выполнение на уже префиксированных
строках **снимает префиксы** (undo): снимается каждая строка выделения, если все
строки помечены; `shouldUndo` не изменяет выделение (чистая проверка).

### QuoteCommand (`> `)

- **Одна строка:** `[hello]` → `> [hello]`.
- **Курсор в середине строки:** `hello wo|rld` → `> [hello world]` (цитируется вся строка).
- **Внутри текста:** только текущая строка, без добавления пустых строк:
  `a\n[b]\nc` → `a\n> [b]\nc`.
- **Несколько строк:** `[a\nb]` → `[> a\n> b]` (каждая строка цитируется).
- **Частичное выделение** расширяется до целых строк: `a1\nb2\nc3`, выделено `1\nb2` →
  `> a1\n> b2\nc3`.
- **Пустой редактор:** `> |`.
- **Повторное нажатие (undo):**
  - `> [hello]` → `[hello]`;
  - курсор внутри процитированной строки: `hello\n> wo|rld\n!` → `hello\n[world]`;
  - каждая строка многострочной цитаты: `[> a\n> b]` → `[a\nb]`;
  - внутри текста только текущая строка: `a\n[> b]\nc` → `a\n[b]\nc`;
  - пустой маркер: `> |` → удаляется.

### HeadingLevel1Command … HeadingLevel6Command (`# ` … `###### `)

- **Одна строка:** `[title]` → `# [title]`.
- **Курсор в середине строки:** `hello wo|rld` → `# [hello world]` (вся строка — заголовок).
- **Внутри текста:** только текущая строка: `a\n[b]\nc` → `a\n# b\nc`.
- **Несколько строк:** каждая строка — заголовок: `[a\nb]` → `[# a\n# b]`.
- **Пустой редактор (H2):** `## |`.
- **Повторное нажатие (undo):** префикс снимается со строки (в т.ч. при курсоре
  внутри заголовка и с каждой строки многострочного выделения):
  `# [title]` → `[title]`, `hello\n# wo|rld\n!` → `hello\n[world]`, `[# a\n# b]` → `[a\nb]`.

### UnorderedListCommand (`- `)

- **Одна строка:** `[hello]` → `- [hello]`.
- **Курсор внутри слова:** `hello wo|rld` → `- [hello world]` (пункт — вся строка).
- **Несколько строк:** `[a\nb]` → `[- a\n- b]`.
- **Внутри абзаца:** отбивается пустыми строками (списки в CommonMark не могут прерывать
  абзац): `start\nli|ne\nend` → `start\n\n- [line]\n\nend`.
- **Пустой редактор:** `- |`.

### OrderedListCommand (`N. `)

- **Одна строка:** `[hello]` → `1. [hello]`.
- **Несколько строк:** нумерация с 1: `[a\nb\nc]` → `[1. a\n2. b\n3. c]`.

### CheckedListCommand (`- [ ] `)

- **Одна строка:** `[hello]` → `- [ ] [hello]` (значение `- [ ] hello`, выделен `hello`).
- **Несколько строк:** `[a\nb]` → `[- [ ] a\n- [ ] b]`.

## TextareaController

| Метод                                         | Поведение                                                                                                                                 |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `getState()`                                  | возвращает `{ text, selection }`; бросает `No TextAreaRef`, если ref пуст                                                                 |
| `setSelection({start, end})`                  | устанавливает выделение и фокусирует textarea                                                                                             |
| `replaceSelection(text)`                      | заменяет выделенный текст / вставляет в позицию курсора                                                                                   |
| `selectWordByCursor()`                        | выделяет слово под курсором; непустое выделение сохраняет                                                                                 |
| `wrapSelection(prefix, suffix)`               | оборачивает выделение; итоговое выделение — текст без префикса/суффикса (в т.ч. при разных prefix/suffix: `[text](url)` → выделен `text`) |
| `unwrapSelection(prefixLength, suffixLength)` | снимает указанное число символов по краям выделения                                                                                       |
| `replaceText(search, replace)`                | заменяет первое вхождение; если не найдено — ничего не делает                                                                             |
| `moveCursorToTheEnd()`                        | перемещает курсор в конец текста                                                                                                          |

## Низкоуровневые утилиты (textHelpers)

- `getWordSelection` — расширяет курсор до границ слова; разделители: пробел и `\n`.
- `getLineSelection` — расширяет выделение до целых строк.
- `selectAfterWord` — схлопывает выделение в позицию сразу после слова.
- `getBreaksNeededForEmptyLineBefore/After` — сколько переводов строк (0–2) нужно,
  чтобы отделить блок пустой строкой от соседнего текста; пробелы игнорируются,
  на первой/последней строке — 0; результат не бывает отрицательным.
- `insertBeforeEachLine` — вставляет строку- или функцию-маркер перед каждой строкой;
  для недопустимого типа маркера бросает ошибку.
- `insertToSelection` — вставка текста с кроссбраузерными фоллбэками:
  `document.execCommand('insertText')` → `setRangeText` → замена всего value
  (с событием `input`) → легаси `document.selection` (IE); перед вставкой фокусирует поле.
